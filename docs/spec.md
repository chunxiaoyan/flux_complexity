# flux_complexity — 计算规格（v0.3，已确认）

本文档定义所有指标的**精确口径**。后续代码、测试、网页显示都以本文档为准；口径如有变动，先改本文档。

**v1 只关注 flux，只计算两个指标：flux size 和 flux weight。** 依存距离（DD）和 MDD 不计算。

---

## 1. 输入

| 来源 | 格式 | scheme | 用途 |
|---|---|---|---|
| 用户输入文字 | 原始文本 → Stanza 分析 → CoNLL-U | 一律 UD | 小白分析页 |
| 用户上传文件 | `.conllu` | 用户声明 UD 或 SUD | 小白分析页（次要入口）/ 实验部分 |
| 参考语料 | `.conllu`（UD / SUD 官方发布版） | UD 或 SUD | 生成常模 |

- 每个语料必须带 `scheme ∈ {UD, SUD}`。scheme 决定：① 可用的预处理变换；② 与哪套常模比较。
- 小白输入文字 → 只与 **UD 常模**比较。上传的 SUD 文件 → 与 SUD 常模比较。

## 2. 基本单位：句法词

- 计算在**句法词**上进行（CoNLL-U 中 ID 为整数的行）。
- **多词符**（MWT，ID 形如 `3-4`，如法语 *du* = *de* + *le*）：不参与计算；只用于展示时把句法词映射回表层词形。
- **空节点**（ID 形如 `8.1`，enhanced 依存）：忽略。
- 只用 HEAD/DEPREL 列（基本依存），忽略 DEPS 列。

## 3. 预处理（按顺序执行的变换链）

预处理是一条可插拔的变换链。每个变换声明自己适用的 scheme。v1 的默认链：

| 顺序 | 变换 | 适用 scheme | v1 状态 |
|---|---|---|---|
| 1 | 去标点 | UD, SUD | ✅ 默认开启，不可关闭 |
| 2 | 切断 parataxis | UD, SUD | ✅ 默认开启 |
| 3 | 去功能词 | **仅 UD** | ⏸ 只留接口，不实现；SUD 语料下界面置灰 |

### 3.1 去标点
- **判定**：`UPOS == PUNCT`。
- **标点有子节点**（多为 parser 错误）：把这些子节点改挂到该标点的支配词上（如该支配词也是标点，则继续向上找，直到非标点或 root），并记录一条警告（句子 ID + 涉及的词）。**不丢弃整句。**
- 删除标点后对剩余句法词**重新编号**为 1..n，并保留"新编号 ↔ 原编号"对照表。
- 之后的所有 flux 位置都在**新编号**上定义（标点不占位置）。
- 展示时用原编号把结果映射回原句，标点照常显示。

### 3.2 切断 parataxis
- DEPREL 的主类型（`:` 之前的部分）为 `parataxis` 的依存（含 `parataxis:*` 子类型）**整条移除**，不计入任何 flux。
- 被切断的从属词仍留在句中，词序与编号不变。
- 注：旧代码 `update_parataxis_gov` 的源码已丢失，本口径可能与旧结果有细微差异；回归测试时会单独标注。

## 4. 参与 flux 的依存

- 依存 = 一对 (支配词 g, 从属词 d)，g、d 为去标点后的新编号。
- **不含** root 弧（HEAD = 0），**不含**被切断的 parataxis。
- 每条依存同时记录 DEPREL 和方向（g 在 d 左 / 右），供实验部分按关系查询和展示 flux 内容；**不作为指标计算。**

## 5. flux 层：size 与 weight

- **位置 i**（1 ≤ i ≤ n−1）：句法词 i 与 i+1 之间的间隔。
- **flux(i)** = 所有满足 `min(g,d) ≤ i < max(g,d)` 的依存。
- **空 flux**：flux(i) 为空集 → 该位置**不产生记录**，不计入任何平均值或分布。（只在 parataxis 切断或多 root 时出现。）
- **size(i) = |flux(i)|**。
- **weight(i)** = flux(i) 中**两两不共享端点**的依存的最大数量。
  - 实现：在左端点集合与右端点集合之间构成的二分图上求**最大匹配**。（在 flux(i) 中，一个词不可能同时是左端点和右端点，所以"两两不共享端点"就等价于二分图匹配。）
  - 旧代码的叶子消去法在树上与最大匹配结果完全一致（已在 14 个语料文件上验证）；新代码直接用最大匹配，对任意输入都正确。
- **句子层汇总**：最大 size、平均 size、最大 weight、平均 weight（只对非空位置平均）。
- **语料层汇总**：以上两个指标在所有非空 flux 位置上的分布（均值、标准差、各取值的频数）。

## 6. 手算例句（同时作为单元测试）

以下数字已用独立脚本验证。

### 例 1：基本情况
`Le chat de ma sœur dort .`

| ID | 词 | UPOS | HEAD | DEPREL |
|---|---|---|---|---|
| 1 | Le | DET | 2 | det |
| 2 | chat | NOUN | 6 | nsubj |
| 3 | de | ADP | 5 | case |
| 4 | ma | DET | 5 | det |
| 5 | sœur | NOUN | 2 | nmod |
| 6 | dort | VERB | 0 | root |
| 7 | . | PUNCT | 6 | punct |

去标点后 n = 6，共 5 个位置。

| 位置 | 间隔 | flux | size | weight |
|---|---|---|---|---|
| 1 | Le \| chat | (1,2) | 1 | 1 |
| 2 | chat \| de | (2,6) (2,5) | 2 | 1 |
| 3 | de \| ma | (2,6) (2,5) (3,5) | 3 | **2** |
| 4 | ma \| sœur | (2,6) (2,5) (3,5) (4,5) | 4 | **2** |
| 5 | sœur \| dort | (2,6) | 1 | 1 |

句子层：最大 size = 4，平均 size = 11/5 = 2.2；最大 weight = 2，平均 weight = 7/5 = 1.4。

### 例 2：parataxis 切断 + 空 flux
`Il pleut , je reste .`（*reste* —parataxis→ *pleut*）

去标点后：Il(1) pleut(2) je(3) reste(4)。parataxis 被切断。

| 位置 | 间隔 | size | weight |
|---|---|---|---|
| 1 | Il \| pleut | 1 | 1 |
| 2 | pleut \| je | — | **空 flux，排除** |
| 3 | je \| reste | 1 | 1 |

句子层：平均只在位置 1、3 上计算，平均 size = 平均 weight = 1.0。

### 例 3：标点带子节点（parser 错误）
`Il dit : « non »`，其中 *non* 被错误地挂在 `:` 上。

→ 警告："non 的支配词是标点 :，已改挂到 dit"。去标点后：Il(1) dit(2) non(3)；位置 1、2 的 size = weight = 1。

## 7. 常模（参考分布）

- **语料**：法语三个 treebank，UD 与 SUD 两个版本都做，使用同一发布版本，版本号写入常模文件：

  | treebank | 类型 | UD | SUD |
  |---|---|---|---|
  | French-Sequoia | 书面语（多领域） | UD_French-Sequoia | SUD_French-Sequoia |
  | French-ParisStories | 口语（叙事） | UD_French-ParisStories | SUD_French-ParisStories |
  | French-Rhapsodie | 口语（多种语体） | UD_French-Rhapsodie | SUD_French-Rhapsodie |

- 每个 (scheme, treebank) 生成一份 JSON，同时每个 scheme 生成一份三个 treebank 合并的总常模，共 8 份。内容包括：
  - **size、weight**（离散值）：每个取值 k 的频数，以及尾部比例 `P(X ≥ k)`，k = 1..max；
  - 元信息：语料名、版本、句数、非空 flux 位置数、预处理链、生成日期、代码版本。
- 安装包里只附带常模 JSON，不附带语料本身；另外提供命令，可以从原始语料重新生成。

## 8. 小白页的标红规则（v1）

| 对象 | 依据 | 颜色 |
|---|---|---|
| 词间位置（flux） | 当前指标的尾部比例 `P(X ≥ 当前值)`，X 为 weight 或 size | ≤ 10% 浅红，≤ 5% 中红，≤ 2% 深红 |
| 整句 | 句中最大 weight / size 在常模中的尾部比例 | 文字说明，如"这句话里有一个位置的 weight 达到 3，参考语料中只有 2% 的位置达到这个值" |

- 鼠标悬停在某个位置上：显示 size、weight 的数值，并在句子上高亮这个 flux 包含的依存。
- 阈值做成配置项，界面上附说明文字。
- 位置落在多词符内部（如 *du* = de|le 之间）时，把颜色标在该表层词形上。

## 9. 已确认的决定（2026-11-06）

1. 小白页默认常模：**UD Sequoia**；界面上可切换为 ParisStories、Rhapsodie 或三者合并。
2. 小白页默认按 **weight** 标红，开关切换为 size；悬停时两个数值都显示。
3. 颜色阈值：10% / 5% / 2%（可配置）。
