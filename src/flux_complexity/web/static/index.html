Comment lire le résultat ?

Entre deux mots voisins, on compte les liens syntaxiques (dépendances) qui passent par-dessus cet endroit : ce sont des relations commencées mais pas encore terminées. On appelle cet ensemble le flux.

  • Taille : le nombre de liens qui traversent cet endroit.
  • Poids : le plus grand nombre de ces liens qui ne partagent aucun mot. Un poids élevé signifie que plusieurs constructions indépendantes sont imbriquées les unes dans les autres ; le lecteur doit alors garder plusieurs choses en mémoire en même temps.

Chaque phrase est affichée avec son arbre de dépendances : au-dessus de chaque mot, sa catégorie (NOUN = nom, VERB = verbe, DET = déterminant…) ; chaque flèche part d'un mot et pointe vers le mot qui dépend de lui, avec le nom de la relation. Les cases colorées entre les mots donnent la valeur du flux.

La couleur indique si la valeur est rare dans un corpus de référence de textes français (par défaut, le corpus écrit Sequoia). La ponctuation n'est pas prise en compte dans le calcul.

L'analyse syntaxique est automatique (Stanza) : elle peut contenir des erreurs, surtout pour des phrases longues ou peu usuelles.
